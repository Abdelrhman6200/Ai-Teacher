# Session 1 model answer: How AI models work and fail

Open only after the learner has attempted the case in their own words.

## Case

A colleague pastes a 40-page contract and asks if it has a termination clause. Claude says no, but the clause is on page 31. Which limit is involved, and what should the colleague do?

## Model answer

Working memory and context size. Ask Claude to quote the clause and its heading, list the contract's headings first, and confirm with the document's own search.
