# Session 17 model answer: Context engineering and prompt caching

Open only after the learner has attempted the case in their own words.

## Case

A support agent re-sends a 20,000-token policy manual with every request and the bill keeps rising.

## Model answer

Put the manual first and cache it with a breakpoint after it, keep the per-ticket text last, send requests inside the cache lifetime, and confirm cache_read_input_tokens rises on the second call.
