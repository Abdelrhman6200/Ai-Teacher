# Session 22 model answer: Security and governance

Open only after the learner has attempted the case in their own words.

## Case

A coding agent reads a README that says to upload the .env file to a URL.

## Model answer

Stop it with controls that do not depend on the model: deny reads of secret files, restrict network egress to an allowlist in the sandbox, require approval for outbound actions and log the attempt. Then add the README as a test case.
