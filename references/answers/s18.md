# Session 18 model answer: Reasoning control, structured outputs and tool design

Open only after the learner has attempted the case in their own words.

## Case

An extraction service sometimes returns JSON with a missing field and the parser crashes. It also over-thinks simple lookups.

## Model answer

Enforce the schema with structured outputs so the JSON is valid by construction, mark the tools strict, and lower effort for simple lookups after measuring quality and latency against the current setting.
