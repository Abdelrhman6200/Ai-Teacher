# Session 14 model answer: Agents and the Agent SDK

Open only after the learner has attempted the case in their own words.

## Case

An operations team wants a weekly cohort report.

## Model answer

Haiku 5.5 extracts and classifies the attendance data, Sonnet 5.5 writes the report, Opus 5.5 reviews it against the source, a human approves before it is sent, and every agent writes to its own file.
