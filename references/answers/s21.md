# Session 21 model answer: MCP servers, skills and plugins at scale

Open only after the learner has attempted the case in their own words.

## Case

An internal MCP server forwards each user's token to a downstream billing API, and a plugin installs a server nobody reviewed.

## Model answer

Stop the passthrough: the server validates tokens issued for it and calls the billing API with its own credentials bound to the user. Restrict marketplace and server sources with managed settings, and review the plugin before it is listed.
