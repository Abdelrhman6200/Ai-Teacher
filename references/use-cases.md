# Finding a real task: Anthropic's use-case gallery

Verified 17 Nov 2026: academy.claude.com/use-cases (the old address claude.com/resources/use-cases redirects there). It is a free library of role-based task recipes. The listing shows a title, an estimated time (10 or 15 minutes in the entries seen), a category tag and, for some, a product tag (Claude, Claude Cowork, Claude Tag). It does not show a starter prompt, model or features; open an entry to see what it contains.

Category filters on the page: General, Marketing, Product, Engineering, HR, Finance, Operations, Data, Design, Legal, Sales, Research, Education, Personal.

## How to use it for this course

1. Filter by the category closest to the learner's job, then list three tasks the learner did in the last two weeks.
2. Pick the gallery entry that matches one of those tasks. If none matches, use the gallery only as a pattern and design the task from the learner's own work.
3. If the entry gives a prompt, run it against the learner's real material, not the sample.
4. Judge how much of the output is usable as is. That judgement, with the evidence, is the start of a "Real task" for the gate rubric.

## Matching a task to a session

| The learner's task looks like | Start in session |
|---|---|
| Summarise, extract or rewrite documents | 4 and 5 |
| Produce a doc, deck or sheet from one brief | 6 |
| Repeated work with fixed context | 7 |
| Pull from or write to the team's apps | 8 |
| A step done the same way every week | 9 and 10 |
| A multi-step process with checks and a schedule | 11 |
| Work inside a code repository | 12 and 13 |
| A process that needs decisions and tools | 14 and 20 |
| Anything that must be measured before it is trusted | 15 and 19 |

A gallery entry is a starting pattern, not a deliverable. The deliverable must be the learner's own work on the learner's own task.
