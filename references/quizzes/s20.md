# Session 20 quiz: Agent architectures and orchestration

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

When is a workflow better than an agent?
- A. When the steps are known in advance
- B. Never
- C. Always
- D. Only when cost is irrelevant

Key: A. Why: Fixed code paths are cheaper and more predictable.

## Q2

Do sub-agents inherit the parent agent's permissions?
- A. No: set permissions for each one
- B. Yes, always
- C. Only in bypass mode
- D. Only for read tools

Key: A. Why: Each sub-agent may request permissions separately.

## Q3

What is the key difference between a workflow and an agent?
- A. Workflows use no model
- B. Agents never use tools
- C. They are identical
- D. A workflow follows fixed code paths; an agent chooses its own steps

Key: D. Why: Use an agent only when the steps cannot be known in advance.

## Q4

Which task suits parallelization by sectioning?
- A. Independent parts handled at the same time
- B. Strictly sequential steps
- C. A single short question
- D. Nothing

Key: A. Why: Sectioning splits independent work.

## Q5

Why can a multi-agent system be worth its cost?
- A. It always uses fewer tokens
- B. Sub-agents search in parallel in their own contexts and return compressed findings
- C. It needs no prompts
- D. It removes the need for evals

Key: B. Why: It suits broad, high-value work.

## Q6

Which is enforced rather than advice?
- A. A sentence in the system prompt
- B. A friendly reminder
- C. A PreToolUse hook that blocks a command
- D. A comment in the code

Key: C. Why: Hooks, deny rules and budgets are enforced.

## Q7

A sub-agent needs to write files. What do you do?
- A. Assume it inherited yours
- B. Give it bypass mode
- C. Skip permissions
- D. Grant it that permission explicitly

Key: D. Why: Sub-agents do not inherit the parent's permissions.

## Q8

What belongs in a progress file?
- A. What is done, what is next and how to resume
- B. Only the prompt
- C. Passwords
- D. A joke

Key: A. Why: The next window starts from it.

## Q9

What are the three main objects in Managed Agents?
- A. Prompt, model and token
- B. Agent, environment and session
- C. Folder, file and link
- D. User, admin and owner

Key: B. Why: Events flow between your application and the session.

## Q10

What keeps agents on track over many hours?
- A. Bigger prompts
- B. Higher temperature
- C. Tests that define done, plus a progress file
- D. Fewer tools

Key: C. Why: Tests and artifacts carry state and judge progress.

## Fill in the blank

- Sub-agents do not ____ the parent's permissions. Key: inherit
- A hook that blocks a call is ____, not advice. Key: enforced

## Matching

Match each pattern to when it fits.

- Routing = Each input goes to the right handler
- Orchestrator-workers = A lead delegates steps it could not predict
- Evaluator-optimizer = One model generates, another grades and refines
- Parallelization = Independent parts run at once, or several votes compare
