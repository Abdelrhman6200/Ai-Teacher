# Session 21 quiz: MCP servers, skills and plugins at scale

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which transport suits a shared remote MCP server?
- A. stdio
- B. Streamable HTTP
- C. Email
- D. FTP

Key: B. Why: stdio is for local processes. HTTP with SSE is deprecated.

## Q2

What must an MCP server do with an access token?
- A. Validate that it was issued for this server
- B. Forward it to any API
- C. Place it in the prompt
- D. Ignore it

Key: A. Why: Tokens meant for other services must be rejected.

## Q3

Which transport fits a shared remote server?
- A. stdio
- B. Email
- C. FTP
- D. Streamable HTTP

Key: D. Why: stdio is for local processes.

## Q4

A local stdio server needs an API key. Where does it come from?
- A. The environment
- B. The prompt
- C. The tool result
- D. A public page

Key: A. Why: Local servers take credentials from the environment.

## Q5

Why check a token's audience?
- A. To shorten it
- B. To be sure it was issued for this server
- C. To log the user
- D. To refresh it

Key: B. Why: Tokens meant for other services must be rejected.

## Q6

Which token types may a server accept?
- A. ID tokens
- B. Any string
- C. Access tokens only
- D. Cookies only

Key: C. Why: Never accept an ID token as an access token.

## Q7

What does a read-only hint signal?
- A. The tool is secret
- B. The tool is slow
- C. The tool is free
- D. The tool has no side effects, so calls can run in parallel

Key: D. Why: Keep read and write tools separate.

## Q8

What do you write before a long skill?
- A. Evaluation scenarios built from observed failures
- B. A logo
- C. The changelog
- D. A press release

Key: A. Why: Evaluations first, minimal instructions second.

## Q9

A new skill makes an older skill stop triggering. Which test catches it?
- A. Isolation testing
- B. Coexistence testing
- C. Cost testing
- D. Spell checking

Key: B. Why: Check that the new skill does not steal triggers.

## Q10

Which control stops members adding unreviewed marketplaces?
- A. A line in CLAUDE.md
- B. A hint in a skill
- C. A managed setting that restricts known marketplaces
- D. Nothing can

Key: C. Why: Managed settings take precedence over user settings.

## Fill in the blank

- An MCP server that validates tokens but never issues them is a ____ server. Key: resource
- Forwarding a client's token to another API is called token ____. Key: passthrough

## Matching

Match each MCP term to what it is.

- Tool = An action the model can call
- Resource = Data the host can read
- Prompt = A reusable template
- stdio = A local transport on the user's machine
