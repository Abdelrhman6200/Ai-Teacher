# Session 4 quiz: Prompting that meets success criteria

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Output format keeps changing between runs. Most direct fix?
- A. Capital letters
- B. 3 to 5 diverse examples in example tags
- C. Switch to Haiku
- D. Raise max tokens.

Key: B.

## Q2

You send a 60-page report and one question. Where does the question go?
- A. At the top
- B. At the end, after the document
- C. In the middle
- D. In a separate chat.

Key: B.

## Q3

What should exist before you start prompt engineering?
- A. A bigger model
- B. A very long system prompt
- C. A list of banned words
- D. Success criteria, a way to test them and a first draft

Key: D. Why: Prompt engineering starts from criteria and a test.

## Q4

How many examples do the guidelines suggest?
- A. 3 to 5 relevant, diverse examples
- B. One example only
- C. As many as fit, at least 50
- D. No examples, ever

Key: A. Why: Wrap them in example tags.

## Q5

What do consistent XML tags do in a prompt?
- A. Speed up the model
- B. Separate instructions, context, examples and inputs
- C. Replace the need for instructions
- D. Turn on thinking

Key: B. Why: Tags make the structure unambiguous.

## Q6

Which instruction follows the guidance to say what to do?
- A. Don't be wordy
- B. Never use bullet points
- C. Write in plain paragraphs of under 120 words
- D. Avoid long answers

Key: C. Why: Say what to do, not what to avoid.

## Q7

Why explain the reason behind a constraint?
- A. It lowers the price
- B. It makes the output longer
- C. The API requires it
- D. So Claude can generalise from it

Key: D. Why: A reason lets Claude apply the constraint to new cases.

## Q8

You write 'can you suggest changes to this function'. What do you most likely get?
- A. Suggestions, not edits
- B. The function rewritten in place
- C. An error
- D. Tests written automatically

Key: A. Why: 'Can you suggest changes' gets suggestions; 'change this function' gets edits.

## Q9

A clear prompt still fails on the hardest task. What does the guidance say?
- A. Add capital letters
- B. Prompting fixes only what the prompt controls; some problems need a different model
- C. Repeat the prompt three times
- D. Remove all context

Key: B. Why: Decide: better prompt, different effort or different model.

## Q10

What does a one-sentence role do?
- A. Raises the context window
- B. Gives access to tools
- C. Focuses tone and behaviour
- D. Fixes factual errors

Key: C. Why: One sentence of role is enough.

## Fill in the blank

- A useful test of a prompt is whether a ____ with minimal context could follow it. Key: colleague
- Say what to do, not what to ____. Key: avoid

## Matching

Match each problem to its fix.

- Format drifts = Give 3 to 5 diverse examples in example tags
- Long document = Put the documents first and the question last
- Vague output = Be clear and direct, and explain why each constraint matters
- Wrong tone = Add a one-sentence role and an example of the voice
