# Session 24 quiz: Expert capstone: ship, drill, teach

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

What turns a failure drill into lasting value?
- A. A postmortem that adds a new test
- B. Finding someone to blame
- C. Deleting the logs
- D. Ignoring it

Key: A. Why: Failures become tests.

## Q2

What does the runbook enable?
- A. An on-call person who is not the author can run and fix the system
- B. Faster models
- C. A bigger prompt
- D. Nothing

Key: A. Why: Handover is tested by a second person.

## Q3

What makes a system production-ready?
- A. It ran once
- B. It has a logo
- C. It is long
- D. Evidence in eval, tracing, security, reliability, cost and ownership

Key: D. Why: Each row needs evidence.

## Q4

Who must be able to run the system from the runbook?
- A. Someone other than the author
- B. Only the author
- C. Nobody
- D. Claude alone

Key: A. Why: Handover is tested by a second person.

## Q5

What comes first in a live failure?
- A. Delete the logs
- B. Detect it from alerts or traces, then contain it
- C. Rewrite the prompt
- D. Wait and see

Key: B. Why: Contain before you fix.

## Q6

What must a postmortem include besides the cause?
- A. A culprit
- B. A joke
- C. A new test added to the suite
- D. A new logo

Key: C. Why: Failures become tests.

## Q7

What is the right tone for a postmortem?
- A. Find who to blame
- B. Hide the cause
- C. Skip the actions
- D. Blameless: fix the system

Key: D. Why: Causes live in the system.

## Q8

What proves a rollback is possible?
- A. Pinned versions and written rollback steps that were rehearsed
- B. A hope
- C. A new model
- D. A longer prompt

Key: A. Why: Test the rollback in the drill.

## Q9

The system degrades after a model change. What first?
- A. Rewrite every prompt
- B. Rerun the eval suite on the new model and compare
- C. Delete the tools
- D. Ignore it

Key: B. Why: The suite pinpoints the regressed cases.

## Q10

How does the learner close Level 5?
- A. Stop learning
- B. Delete the capstone
- C. Teach a session, write the rollout plan, list the next skills and keep the monthly routine
- D. Avoid review

Key: C. Why: Ship it, drill it, teach it.

## Fill in the blank

- A blameless write-up of a failure is a ____. Key: postmortem
- A guide that lets an on-call person run and fix the system is a ____. Key: runbook

## Matching

Match each item to what it contains.

- Runbook = How to run, monitor, fix and roll back
- Postmortem = Timeline, cause, actions and a new test
- Failure drill = A deliberate breakage to test the response
- Adoption plan = Access, policy, training and monitoring for a team
