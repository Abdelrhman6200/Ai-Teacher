# Session 5 quiz: Documents, research and verification

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Best way to reduce unsupported claims in a summary?
- A. Ask for a shorter summary
- B. Require a supporting quote for each claim and check the quotes in the source
- C. Ask "are you sure?"
- D. Use a bigger model only.

Key: B.

## Q2

Claude cites a paper you cannot find. First step?
- A. Assume it exists
- B. Search the title or DOI, and treat it as unverified if it cannot be found
- C. Ask Claude to confirm
- D. Cite it anyway.

Key: B.

## Q3

What does asking for quotes first protect against?
- A. Slow answers
- B. Long outputs
- C. Formatting errors
- D. Claims with no support in the source

Key: D. Why: Quotes make each claim traceable.

## Q4

Which three things should you separate when reading a brief?
- A. What the source says, what Claude infers and what lies outside the sources
- B. Headline, body and footer
- C. Past, present and future
- D. Easy, medium and hard

Key: A. Why: That separation is the core of Discernment.

## Q5

Which columns does the verification table have?
- A. Claim, price, model, effort
- B. Claim, source, checked by, status
- C. Author, title, year, pages
- D. Prompt, output, tokens, cost

Key: B. Why: The table travels with the brief.

## Q6

A number in the summary differs from the source. What wins?
- A. The summary, since it is fluent
- B. Whichever number is larger
- C. The source; fix the summary
- D. The average of the two

Key: C. Why: Check numbers against the source.

## Q7

Why plant a false statement in a document?
- A. To slow the learner down
- B. To train the model
- C. To test the model's price
- D. To see whether the learner catches it and whether Claude flags it

Key: D. Why: It tests premise-error detection.

## Q8

A fact changed this year. What do the sources say to do?
- A. Use search or provided files, and open the sources
- B. Trust the model's memory
- C. Ask the same question three times
- D. Raise the effort level

Key: A. Why: Knowledge stops at the cutoff.

## Q9

Which D is owning what you then send or publish?
- A. Delegation
- B. Diligence
- C. Description
- D. Discernment

Key: B. Why: Discernment evaluates; Diligence owns.

## Q10

Which request surfaces evidence best?
- A. A one-line answer
- B. Conclusions only
- C. Documents first, question last, and quotes before conclusions
- D. A longer answer

Key: C. Why: That order keeps claims tied to text.

## Fill in the blank

- Ask for quotes first, then the ____. Key: conclusion
- Never accept a ____ you have not opened. Key: citation

## Matching

Match each error type to an example.

- Fabricated citation = A paper that cannot be found by title or DOI
- Outdated fact = A figure that changed after the model's cutoff
- Misread number = 12 percent in the summary, 21 percent in the source
- Unsupported inference = A conclusion the source does not state
