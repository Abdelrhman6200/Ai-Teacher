# Session 22 quiz: Security and governance

Contents: Q1 to Q10, fill in the blank.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which holds even if the model is fooled by an injected instruction?
- A. A deny rule or a sandbox
- B. A polite prompt
- C. A skill
- D. CLAUDE.md

Key: A. Why: Enforced controls do not depend on the model complying.

## Q2

A deny rule blocks the web fetch tool, but Bash is allowed. What can still reach any URL?
- A. curl run in Bash
- B. Nothing
- C. The fetch tool
- D. The sandbox

Key: A. Why: Permission rules and the sandbox cover different layers.

## Q3

What is indirect prompt injection?
- A. A user typing in the chat box
- B. A slow network
- C. A billing error
- D. Instructions hidden in content the agent reads

Key: D. Why: It arrives through pages, files or tool results.

## Q4

Is prompt injection solved?
- A. No: design so a fooled model cannot do serious harm
- B. Yes, by the system prompt
- C. Yes, by caching
- D. Yes, by Batch

Key: A. Why: Defence is layered.

## Q5

Which combination concentrates risk in an agent?
- A. Speed, cost and size
- B. Private data, untrusted content and a way to act or send outward
- C. Prompts, skills and hooks
- D. Users, admins and owners

Key: B. Why: Remove at least one of the three.

## Q6

A hook blocks a command. What kind of control is it?
- A. Advice
- B. Decorative
- C. Enforced
- D. Optional for the model

Key: C. Why: It holds even if the model is fooled.

## Q7

Why does a sandbox matter beyond a fetch deny rule?
- A. It speeds up Claude
- B. It removes logs
- C. It raises effort
- D. It limits files and network at the OS level, so curl cannot reach arbitrary URLs

Key: D. Why: Permissions and the sandbox cover different layers.

## Q8

Which setting makes managed rules the only permission rules?
- A. allowManagedPermissionRulesOnly
- B. maxEffortLevel
- C. minimumVersion
- D. availableModels

Key: A. Why: Managed values take precedence.

## Q9

How do you check which settings source is winning on a machine?
- A. Ask Claude
- B. Run /status and read the Setting sources line
- C. Read the invoice
- D. Restart the router

Key: B. Why: It lists the managed source in parentheses.

## Q10

Which gives request-level audit logging with identity?
- A. A longer prompt
- B. Lower effort
- C. A gateway between developers and the provider
- D. A skill

Key: C. Why: Gateways can log and route by data sensitivity.

## Fill in the blank

- A ____ rule holds in every permission mode. Key: deny
- Organisation policy that overrides user settings is delivered as ____ settings. Key: managed
