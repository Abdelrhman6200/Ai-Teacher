# Session 1 quiz: How AI models work and fail

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Why can a fluent answer still be wrong?
- A. The model only reads short inputs.
- B. The model generates likely text, which does not guarantee it is true.
- C. Fluency shows the model checked a source.
- D. Wrong answers only come from bad prompts.

Key: B.

## Q2

The learner checks a claim in Claude's answer against the original source. Which D is this?
- A. Delegation
- B. Description
- C. Discernment
- D. Diligence.

Key: C. Why: Discernment is evaluating the output.

## Q3

A question about an event after the model's training cutoff needs which of these?
- A. Nothing, the model updates itself
- B. A longer answer
- C. A higher effort setting
- D. Search or files that contain the information

Key: D. Why: Knowledge comes from training and stops at a cutoff. Anything newer needs search or files.

## Q4

What does the context window hold?
- A. What the model holds right now: the conversation, files and instructions
- B. Everything the model learned in training
- C. Only the latest message
- D. The model's price list

Key: A. Why: Working memory is the context window.

## Q5

Why can a very long chat give worse answers even when it fits in the window?
- A. Long chats are blocked
- B. Everything in the window competes for attention, so long chats need managing
- C. Tokens expire after an hour
- D. The model unlearns its training

Key: B. Why: The window is large, but attention is shared across everything in it.

## Q6

The same model behaves differently under two different instructions. Which limit is this?
- A. Knowledge
- B. Prediction
- C. Steerability
- D. Context size

Key: C. Why: Steerability: the quality of the instruction matters.

## Q7

Which list names the five limits?
- A. Speed, price, size, colour, tone
- B. Delegation, Description, Discernment, Diligence, Delivery
- C. Training, testing, tuning, tagging, tracking
- D. Prediction, knowledge, working memory, steerability, context size

Key: D. Why: The five limits frame every failure in this course.

## Q8

You decide which tasks to hand to Claude and which to keep. Which D is this?
- A. Delegation
- B. Description
- C. Discernment
- D. Diligence

Key: A. Why: Delegation: decide what to hand over.

## Q9

You write the task, the audience and the format so Claude can act on them. Which D is this?
- A. Delegation
- B. Description
- C. Discernment
- D. Diligence

Key: B. Why: Description: describe the task clearly.

## Q10

You publish a report Claude helped write, and you check it first because you own the outcome. Which D is this?
- A. Delegation
- B. Description
- C. Diligence
- D. Discernment

Key: C. Why: Diligence is owning what you then send or publish.

## Fill in the blank

- A model writes text one ____ at a time. Key: token
- Fluent does not mean ____. Key: true

## Matching

Match each limit to an example.

- Prediction = Fluent text that turns out to be false
- Knowledge = A question about an event after the training cutoff
- Working memory = A detail from the middle of a long pasted document is missed
- Steerability = The same model answers differently when the instruction changes
