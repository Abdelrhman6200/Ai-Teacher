# Session 7 quiz: Projects, memory and context

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Standing context for one ongoing client belongs in:
- A. A Project
- B. A skill
- C. The prompt each time
- D. A connector.

Key: A.

## Q2

A very long chat has started to drift. Best move?
- A. Keep going
- B. Summarise the state and start a new chat
- C. Write in capitals
- D. Delete all memory.

Key: B.

## Q3

What does a Project hold?
- A. Only memory
- B. A copy of the model
- C. Billing settings
- D. Its own instructions, files and chats

Key: D. Why: What you put in a Project is available to every chat inside it.

## Q4

Where are the memory options controlled?
- A. In Settings: generate memory from chats, and search and reference past chats
- B. By asking Claude to switch memory off
- C. In the prompt
- D. In the release notes

Key: A. Why: Memory is controlled in Settings.

## Q5

Can Claude switch memory off itself?
- A. Yes, on request
- B. No; the setting in Settings controls it
- C. Yes, but only in Projects
- D. Only on mobile

Key: B. Why: Claude cannot switch memory off itself.

## Q6

Each Project's memory setting is either:
- A. On or deleted
- B. Daily or weekly
- C. Connected to account-level memory or separate
- D. Public or private only

Key: C. Why: Each Project has its own memory setting.

## Q7

What does CLAUDE.md do in Claude Code?
- A. It runs the tests
- B. It replaces the model
- C. It stores billing
- D. It is read at the start of every session

Key: D. Why: CLAUDE.md is the Claude Code version of standing context.

## Q8

What should stay out of memory and Project files unless needed?
- A. Secrets and personal data
- B. Role descriptions
- C. Output rules
- D. Tone preferences

Key: A. Why: Also check who a Project is shared with.

## Q9

How do you carry state into a fresh chat?
- A. Keep the old chat open
- B. Write a short summary of the state and paste it in
- C. Hope memory covers it
- D. Repeat the whole transcript

Key: B. Why: Carry state across with a short summary.

## Q10

After the 16 September change, which carry over across surfaces?
- A. Only chats
- B. Only skills
- C. Chats, Cowork tasks, projects, connectors and skills
- D. Nothing

Key: C. Why: These carry over across surfaces.

## Fill in the blank

- Long chats ____. Start a new chat per task. Key: drift
- Claude Code reads ____ at the start of every session. Key: CLAUDE.md

## Matching

Match where each belongs.

- Preferences you always want = Project instructions
- A procedure you use sometimes = A skill
- A one-off file = Attached to that chat
- A live system = A connector
