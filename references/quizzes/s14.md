# Session 14 quiz: Agents and the Agent SDK

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

You need an agent embedded in your own Python service. Which route?
- A. Claude Code CLI
- B. Agent SDK
- C. Claude chat
- D. A prompt template.

Key: B.

## Q2

Your product wants users to sign in with their claude.ai accounts to use an SDK-based agent. What do the docs say?
- A. It is encouraged
- B. It is not allowed unless approved; use API key authentication
- C. It is required
- D. It works only on mobile.

Key: B.

## Q3

What is an agent?
- A. A single prompt
- B. A saved chat
- C. A model tier
- D. Something that plans its own steps and calls tools in a loop

Key: D. Why: Tools read files, run commands or edit code.

## Q4

Which languages does the Agent SDK offer?
- A. Python and TypeScript
- B. Only Python
- C. Only Java
- D. C and COBOL

Key: A. Why: The Agent SDK is available in Python and TypeScript.

## Q5

What does the Agent SDK give you?
- A. A new model
- B. Claude Code's tools, agent loop and context management
- C. A browser
- D. A billing dashboard

Key: B. Why: You embed that agent in your own app.

## Q6

Which authentication should a third-party product built on the SDK use?
- A. claude.ai login
- B. Shared passwords
- C. API key authentication
- D. No authentication

Key: C. Why: claude.ai login and rate limits need approval.

## Q7

What do the docs say about branding?
- A. Brand it as Claude Code
- B. Use Claude's logo as yours
- C. Branding is required
- D. Do not brand your agent as Claude Code

Key: D. Why: State it plainly in the product.

## Q8

By default, how deep do subagents nest?
- A. Three layers deep, up to 20 at once
- B. One layer
- C. Ten layers
- D. Without limit

Key: A. Why: Subagents nest three layers deep and run up to 20 at once by default.

## Q9

Which design is recommended for an agent team?
- A. One agent with all tools
- B. One job per agent, scoped tools, outputs in files, a manager reading summaries, human approval on every external action
- C. Agents sharing one context
- D. No approvals

Key: B. Why: Six fields per agent: job, tools, model, input, output, approval.

## Q10

Which pattern keeps most tokens on cheaper models?
- A. Always use the largest model
- B. Run everything twice
- C. An orchestrator delegating bulk work to cheaper workers, or an executor escalating to an advisor
- D. Skip evaluation

Key: C. Why: Multi-model patterns.

## Fill in the blank

- An agent plans its own steps and calls ____ in a loop. Key: tools
- Design one ____ per agent, with scoped tools. Key: job

## Matching

Match each route to a need.

- Agent SDK = An agent embedded in your own Python service, in a process you operate
- Claude Code CLI = Interactive work in a repository, and one-off tasks
- Client SDK = Direct API calls where you write the tool loop yourself
- Managed Agents = A hosted harness in an Anthropic cloud sandbox or your own
