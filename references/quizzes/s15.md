# Session 15 quiz: Evals, safety and cost

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which practice does the guidance recommend when an LLM grades outputs?
- A. Use the same model that wrote them
- B. A detailed rubric, a clear verdict or score, and a different grader model where possible
- C. No rubric
- D. Always use humans.

Key: B.

## Q2

Which is enforced rather than advisory?
- A. A CLAUDE.md line
- B. A hook or deny rule
- C. A prompt
- D. A skill Claude chooses to load.

Key: B.

## Q3

Which four qualities do good success criteria have?
- A. Short, cheap, fast and polite
- B. Public, private, shared and open
- C. Daily, weekly, monthly and yearly
- D. Specific, measurable, achievable and relevant

Key: D. Why: Most use cases need several criteria.

## Q4

Besides typical cases, what should an eval include?
- A. Edge cases: empty or overlong input, harmful input, ambiguous cases, topic shifts
- B. Only typical cases
- C. Only cases the model passed
- D. One hard case

Key: A. Why: Evals should mirror the real task.

## Q5

What is the strength of code-based grading?
- A. Best for judging tone
- B. Fastest and most reliable, but limited in nuance
- C. Needs no test cases
- D. Always costs the most

Key: B. Why: Automate grading where possible.

## Q6

How should an LLM grader be set up?
- A. Same model, no rubric
- B. A one-word prompt
- C. A detailed rubric, a clear verdict or 1 to 5 score, thinking on, and a different model from the one graded
- D. A random score

Key: C. Why: Test its reliability first.

## Q7

What is the last check before shipping?
- A. Skip testing
- B. Ask Claude if it is happy
- C. Delete the eval
- D. Check against held-out cases

Key: D. Why: Define, write cases, prompt, test, refine, held-out check.

## Q8

Which is a cost lever?
- A. Tune effort before switching model
- B. Always raise effort
- C. Use the largest model for bulk work
- D. Enable every MCP server

Key: A. Why: Also route bulk work to cheaper models and disable unused MCP servers.

## Q9

Who has the last word on a merge?
- A. The agent
- B. A person approving it
- C. The grader model
- D. Nobody

Key: B. Why: Limits cap cost and time; a person approves the merge.

## Q10

What does fast mode trade for speed?
- A. Lower accuracy only
- B. Free usage
- C. Up to 2.5 times output speed at premium pricing, on supported models
- D. Longer outputs

Key: C. Why: Use it where speed matters.

## Fill in the blank

- Code-based grading is the fastest and most ____ but limited in nuance. Key: reliable
- Prompts, CLAUDE.md and skills are advice; hooks and deny rules are ____. Key: enforced

## Matching

Match each grading method to a case.

- Code-based grading = Does the label match the expected category?
- LLM-based grading = Is the reply polite and complete, judged against a rubric?
- Human grading = A small sample judged by a person for the highest quality
- Held-out cases = Cases not used while refining the prompt, run before shipping
