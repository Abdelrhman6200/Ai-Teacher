# Session 2 quiz: The Claude landscape

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

A developer wants Claude Code's agent inside their own Python application, in a process they operate. Which fits?
- A. Claude Code CLI
- B. Agent SDK
- C. Client SDK
- D. Claude chat.

Key: B.

## Q2

A video shows a feature your Pro account lacks. First check?
- A. Reinstall the app
- B. The release notes and your plan, since rollouts are gradual and some features are beta or plan-limited
- C. Ask Claude to enable it
- D. Wait a year.

Key: B.

## Q3

Where do most people use Claude?
- A. Only in the Claude Code terminal
- B. Only through the API
- C. Only inside Managed Agents
- D. The Claude app on web, desktop and mobile

Key: D. Why: The Claude app is where most people work.

## Q4

Since 16 September 2026, where is everything Cowork does available?
- A. From any conversation
- B. Only in a separate Cowork app
- C. Only on Enterprise
- D. Only in Claude Code

Key: A. Why: Cowork's capabilities are available from any conversation.

## Q5

Which plans include artifacts?
- A. Paid plans only
- B. Every plan, including Free
- C. Enterprise only
- D. None

Key: B. Why: Artifacts are available on every plan, including Free.

## Q6

Claude Code is:
- A. A model tier
- B. A spreadsheet format
- C. An agentic coding tool that reads a codebase, edits files and runs commands
- D. A billing plan

Key: C. Why: It runs in the terminal, IDEs, the desktop app and the web.

## Q7

What is the Claude Platform for?
- A. Reading release notes

- C. Mobile chat only

Key: D. Why: The platform is the building surface.

## Q8

A team wants Claude working inside their terminal and IDE on a repository. Which surface?
- A. Claude Code

- D. Claude chat on mobile

Key: A. Why: Claude Code reads the codebase, edits files and runs commands.

## Q9

Why do the release notes matter?
- A. They contain ready-made prompts
- B. Rollouts are gradual and features start in beta or on specific plans, so they show what exists this month
- C. They list prices only

## Q10

Which route calls the API directly, so you write the tool loop or use the tool runner?
- A. Agent SDK
- B. Claude Code CLI
- C. Client SDK
- D. Managed Agents

Key: C. Why: The Client SDK calls the API directly.

## Fill in the blank

- Claude Code is an agentic coding tool that reads a codebase, edits files and runs ____. Key: commands
- The ____ notes are the source of truth for what exists this month. Key: release

## Matching

Match each to its purpose.

- Client SDK = Call the API directly and write the tool loop, or use the tool runner
- Agent SDK = Embed Claude Code's agent in your own Python or TypeScript app
- Managed Agents = A hosted agent harness
- Claude Code CLI = Interactive work and one-off tasks in the terminal
