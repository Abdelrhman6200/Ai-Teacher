# Session 23 quiz: Cost, latency and reliability engineering

Contents: Q1 to Q10, fill in the blank.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which saving needs no quality trade-off?
- A. Caching a stable prefix and tidying tokens
- B. Dropping the eval
- C. Always using the lowest effort
- D. Using the smallest model everywhere

Key: A. Why: These are the free wins. Trade-offs need an eval.

## Q2

What discount does the Message Batches API give?
- A. 50 percent on input and output
- B. 5 percent
- C. 90 percent
- D. None

Key: A. Why: Use it only for work nobody is waiting on.

## Q3

What comes first when cutting cost?
- A. Switch to the smallest model
- B. Delete the eval
- C. Disable caching
- D. Measure cost per feature from usage data

Key: D. Why: Attack the largest line.

## Q4

What does the Batch API cost relative to standard calls?
- A. Half price on input and output
- B. Double
- C. The same
- D. A tenth

Key: A. Why: Use it for work nobody is waiting on.

## Q5

What happens to a batch not finished in 24 hours?
- A. It is billed double
- B. It expires
- C. It switches model
- D. It keeps running free

Key: B. Why: Plan for expiry and resubmit.

## Q6

Which is a free win?
- A. A smaller model
- B. Lower effort
- C. Prompt caching of a stable prefix
- D. A shorter timeout

Key: C. Why: It does not change quality.

## Q7

A request fails with a rate-limit error. What do you do?
- A. Retry instantly forever
- B. Ignore it
- C. Raise max_tokens
- D. Retry with backoff, within a cap

Key: D. Why: Backoff avoids amplifying the outage.

## Q8

Why use separate workspaces?
- A. To separate keys, limits and spend by team or environment
- B. To rename models
- C. To remove caching
- D. To skip billing

Key: A. Why: The default workspace cannot have spend limits.

## Q9

A new model rejects thinking with a fixed budget. What do you do?
- A. Keep it
- B. Remove it and set effort explicitly
- C. Raise the budget
- D. Use prefill

Key: B. Why: Follow the migration guide and rerun the eval.

## Q10

What proves a model upgrade is safe?
- A. The release name
- B. A rumour
- C. The eval suite on the new model, with cost and latency compared
- D. A longer prompt

Key: C. Why: Migrate by test.

## Fill in the blank

- The Batch API takes ____ percent off input and output. Key: 50
- Retries should use ____ so they do not amplify an outage. Key: backoff
