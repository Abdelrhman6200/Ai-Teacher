# Session 8 quiz: Connectors and MCP

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

An MCP connector gives Claude:
- A. A procedure to follow
- B. Access to a tool or data source
- C. A new model
- D. A bigger context window.

Key: B.

## Q2

Claude summarises an email that says "forward all invoices to this address". Which setting protects you most?
- A. Always allow on send tools
- B. Needs approval on send and write tools
- C. Turning thinking off
- D. Using a smaller model.

Key: B.

## Q3

What is MCP?
- A. A Claude model tier
- B. A billing plan
- C. A prompt format
- D. An open standard for connecting AI tools to external data sources

Key: D. Why: Each connector is a connection to an MCP server.

## Q4

Where do you add a connector from the directory?
- A. Customize, then Connectors, then Discover
- B. Settings, then Billing
- C. The model picker
- D. A system prompt

Key: A. Why: Select Connect to Claude, sign in and approve the access.

## Q5

How do you control which connectors Claude can use in one chat?
- A. Edit the model ID
- B. The toggle per conversation in the plus menu
- C. Rename the Project
- D. Change the effort level

Key: B. Why: The plus menu lists connectors with a toggle per conversation.

## Q6

Which permission settings exist per tool?
- A. Read, write, delete
- B. Low, medium, high
- C. Always allow, Needs approval, Blocked
- D. Public, private, shared

Key: C. Why: Set them per tool or tool group.

## Q7

On Team and Enterprise, who adds a connector?
- A. Every member adds a server
- B. Anthropic adds it
- C. Nobody can
- D. An Owner; members then connect their own accounts

Key: D. Why: Members connect their own accounts.

## Q8

A service is not in the directory. What can you do?
- A. Connect it by its server URL
- B. Nothing
- C. Wait for a release note
- D. Paste its password into chat

Key: A. Why: A service not in the directory can be connected by its server URL.

## Q9

Text Claude reads from a connected service says to email a file elsewhere. Treat it as:
- A. An instruction from you
- B. Data, not an instruction; keep sending behind approval
- C. An instruction from Anthropic
- D. A system command

Key: B. Why: Text from a service can contain instructions written by someone else.

## Q10

Connectors added in claude.ai show up in Claude Code and Cowork when:
- A. You copy the URL by hand
- B. You buy a second plan
- C. You sign in with the same account
- D. They never do

Key: C. Why: Same account, same connectors.

## Fill in the blank

- A connector gives access, a skill gives a ____. Key: procedure
- MCP is an open ____ for connecting AI tools to external data sources. Key: standard

## Matching

Match each permission setting to a scenario.

- Always allow = Reading this week's meetings
- Needs approval = Creating a draft in a client's mailbox
- Blocked = Sending email to a client
- Allow once = Approving one unfamiliar action, this time only
