# Session 19 quiz: Production evals and observability

Contents: Q1 to Q10, fill in the blank.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which grader is fastest and most objective, but brittle?
- A. Code-based
- B. Human
- C. LLM-based
- D. None of them

Key: A. Why: Code checks exact conditions, so it breaks on valid variations.

## Q2

Why keep a held-out set?
- A. To check unseen cases and avoid tuning to the test
- B. To save cost
- C. To train the model
- D. To skip tracing

Key: A. Why: Tuning on every case overfits the score.

## Q3

What comes first when building an eval?
- A. A bigger model
- B. A dashboard
- C. A prompt rewrite
- D. Measurable success criteria

Key: D. Why: Criteria define what to measure.

## Q4

Why run several trials per task?
- A. Outputs vary between runs
- B. Graders are free
- C. It is required by law
- D. To use more tokens

Key: A. Why: One run can mislead.

## Q5

What should an LLM grader be tested against first?
- A. Itself
- B. Human grades on a sample
- C. The price list
- D. A shorter prompt

Key: B. Why: Test reliability before you scale.

## Q6

Where should the first eval cases come from?
- A. Random text
- B. Marketing copy
- C. Real production failures
- D. Nowhere yet

Key: C. Why: Real failures are the cases that matter.

## Q7

A score rose three points after a change. What first?
- A. Ship at once
- B. Delete the eval
- C. Raise effort
- D. Check the environment is fixed, repeat runs and compare with a baseline

Key: D. Why: Infrastructure noise alone can move scores by several points.

## Q8

What does a trace help you do?
- A. Find where a production run failed and turn it into a test
- B. Raise rate limits
- C. Change the model name
- D. Hide errors

Key: A. Why: Traces make failures reproducible.

## Q9

Which logged field exposes truncation?
- A. Colour
- B. Stop reason
- C. Author
- D. Locale

Key: B. Why: A max_tokens stop reason shows a cut-off output.

## Q10

Claude Code telemetry leaves out prompt text by default. How do you include it?
- A. You cannot
- B. Edit the model
- C. Set the log variable for user prompts
- D. Buy a larger plan

Key: C. Why: Prompts, tool details and responses are redacted unless you opt in.

## Fill in the blank

- A set of cases you never tune on is a ____ set. Key: held-out
- One run of one task is called a ____. Key: trial
