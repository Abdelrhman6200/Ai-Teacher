# Session 12 quiz: Claude Code fundamentals

Contents: Q1 to Q10, fill in the blank.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

What belongs in CLAUDE.md?
- A. Everything in the repo
- B. Only what Claude cannot work out from the code, such as test commands and decisions made elsewhere
- C. The full source
- D. Nothing.

Key: B.

## Q2

Claude says it is done but the feature is broken. Best prevention?
- A. Tell it to be thorough
- B. Give it a pass or fail check it can run and ask for the output as evidence
- C. Turn thinking off
- D. Write shorter prompts.

Key: B.

## Q3

Which command drafts a starting CLAUDE.md?
- A. /context
- B. /loop
- C. /mcp
- D. /init

Key: D. Why: /init drafts one; then delete every line Claude could find itself.

## Q4

Which command confirms CLAUDE.md loaded?
- A. /context
- B. /init
- C. --version
- D. /loop

Key: A. Why: /context confirms it loaded.

## Q5

Where do personal preferences go?
- A. CLAUDE.md for everyone
- B. CLAUDE.local.md
- C. The prompt only
- D. A hook

Key: B. Why: Personal preferences go in CLAUDE.local.md.

## Q6

Roughly how long should CLAUDE.md stay?
- A. As long as possible
- B. Over 1,000 lines
- C. Under 200 lines
- D. Exactly one line

Key: C. Why: It loads into every session, so keep it short.

## Q7

What makes a prompt specific?
- A. It is short
- B. It repeats the request
- C. It avoids naming files
- D. It names the file, the symptom and what fixed looks like

Key: D. Why: A specific prompt names all three.

## Q8

You do not yet know what you want. What does the guidance suggest?
- A. Ask Claude to interview you and write SPEC.md, then build from it in a fresh session
- B. Start coding anyway
- C. Wait
- D. Write a longer CLAUDE.md

Key: A. Why: Spec, build, check, evidence.

## Q9

In auto mode, what reviews risky actions?
- A. A human on every step
- B. A classifier
- C. Nothing
- D. The linter

Key: B. Why: New terminal sessions start in auto mode.

## Q10

Which test decides whether a line belongs in CLAUDE.md?
- A. Whether the line is short
- B. Whether the line is polite
- C. Could Claude find this by reading the code, and would it actually look? If both are yes, leave it out
- D. Whether the line is in capitals

Key: C. Why: Tell Claude what it cannot see.

- The docs recommend keeping CLAUDE.md under ____ lines. Key: 200
