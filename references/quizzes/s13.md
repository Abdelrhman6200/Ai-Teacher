# Session 13 quiz: Claude Code extended

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

A rule must hold every time: never edit src/gen/. Where does it go?
- A. CLAUDE.md in capitals
- B. A hook or deny rule
- C. A longer prompt
- D. A skill Claude may choose to load.

Key: B.

## Q2

You delegate to a subagent with a one-line prompt and it fails. Why?
- A. Subagents see the whole conversation
- B. A new subagent starts fresh and sees only the delegation prompt
- C. Subagents cannot read files
- D. Subagents ignore descriptions.

Key: B.

## Q3

Where do project subagents live?
- A. src/agents.py
- B. CLAUDE.md
- C. ~/.claude/hooks
- D. .claude/agents/ as Markdown files with YAML frontmatter

Key: D. Why: Project agents live in .claude/agents/; all-project agents in ~/.claude/agents/.

## Q4

Which fields are required in subagent frontmatter?
- A. name and description
- B. tools and model
- C. model and hooks
- D. version and author

Key: A. Why: tools and model are optional.

## Q5

What returns to the main conversation from a subagent?
- A. Its whole context window
- B. Only a summary
- C. Nothing
- D. Its tools

Key: B. Why: A subagent runs in its own context window.

## Q6

Which hook event can block an action before it runs?
- A. PostToolUse
- B. Stop
- C. PreToolUse, with exit code 2
- D. None of them can block

Key: C. Why: Exit code 2 blocks a PreToolUse action.

## Q7

A PostToolUse hook runs a formatter after each edit. Can it undo the edit?
- A. Yes, always
- B. Yes, with exit code 2
- C. Only inside subagents
- D. No, the tool already ran

Key: D. Why: A hook cannot undo a PostToolUse.

## Q8

What does disable-model-invocation: true do for a skill?
- A. The workflow runs only when you type it
- B. It hides the skill from the account
- C. It deletes the skill
- D. It makes the skill run every turn

Key: A. Why: Use it for side-effect workflows such as a release.

## Q9

Why disable unused MCP servers under /mcp?
- A. They cost money by the day
- B. Their tool names add to context even when unused
- C. They slow the keyboard
- D. They delete memory

Key: B. Why: Connected servers add their tool names to context.

## Q10

Which flags cap a headless run?
- A. --short and --cheap
- B. --stop and --halt
- C. --max-turns and --max-budget-usd
- D. --limit-model

Key: C. Why: claude -p takes limits such as these.

## Fill in the blank

- Use CLAUDE.md to tell Claude what to do and hooks to ____ it. Key: enforce
- A hook exits with code ____ to block a PreToolUse action. Key: 2

## Matching

Match each subagent field to its purpose.

- name = The identifier of the subagent
- description = What it does and when to use it
- tools = Restricts what it can use
- model = Which model it runs: sonnet, opus, haiku, fable, a full ID or inherit
