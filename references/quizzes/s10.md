# Session 10 quiz: Plugins, Cowork and scheduled work

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

A plugin is:
- A. A new model
- B. A package that can hold skills, connectors, commands and agents
- C. A browser extension only
- D. A billing plan.

Key: B.

## Q2

A report must be produced daily even when your laptop is off. Which fits?
- A. /loop
- B. Desktop scheduled task
- C. Cloud scheduled task
- D. A manual chat.

Key: C.

## Q3

What must an uploaded plugin archive hold?
- A. An installer program
- B. A model file
- C. A README only
- D. One .claude-plugin/plugin.json

Key: D. Why: An uploaded archive must hold one .claude-plugin/plugin.json.

## Q4

After you add a plugin, its connectors are:
- A. Not connected until you open its Connectors tab
- B. Connected automatically
- C. Deleted
- D. Blocked forever

Key: A. Why: Its skills load either way.

## Q5

Which plugin sources get automated validation, a security scan and human review of new listings?
- A. A marketplace URL
- B. Directory plugins
- C. An uploaded archive
- D. Any link a colleague sends

Key: B. Why: That review does not cover a marketplace URL or an upload.

## Q6

Which components work in chat, Cowork and Claude Code?
- A. Agents only
- B. Hooks only
- C. Skills, commands and connectors
- D. None of them

Key: C. Why: Agents work in Cowork and Claude Code.

## Q7

A task must run on a schedule using files on your own machine. Which fits?
- A. A cloud scheduled task
- B. A /loop in a closed session
- C. A manual chat
- D. A desktop scheduled task

Key: D. Why: Desktop scheduled tasks run on your machine with your local files.

## Q8

What does /loop do?
- A. Repeats a prompt inside a CLI session
- B. Schedules a cloud run while your computer is off
- C. Installs a plugin
- D. Blocks a tool

Key: A. Why: The three ways: cloud, desktop and /loop.

## Q9

What does unattended work need first?
- A. A bigger model
- B. Clear success criteria, read-only access first, defined approvals and a report someone reads
- C. No approvals, to run faster
- D. Write access first

Key: B. Why: Start read-only.

## Q10

On Team and Enterprise, a plugin can be shared with:
- A. Only its creator
- B. Only Anthropic
- C. Specific people, or published to the organisation
- D. Only Free users

Key: C. Why: Create with Claude or by writing files, then share.

## Fill in the blank

- Cloud scheduled tasks keep running when your computer is ____. Key: off
- An uploaded plugin archive must hold one .claude-plugin/____. Key: plugin.json

## Matching

Match each to where it works or runs.

- Skills, commands and connectors = Chat, Cowork and Claude Code
- Agents = Cowork and Claude Code
- Cloud scheduled task = Runs even when your computer is off
- Desktop scheduled task = Runs on your machine with your local files
