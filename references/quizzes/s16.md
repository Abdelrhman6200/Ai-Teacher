# Session 16 quiz: Capstone and staying current

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

A model your workflow calls is marked deprecated. First action?
- A. Ignore it
- B. Check the deprecations page for the retirement date and replacement, run your eval on the replacement, then switch
- C. Switch immediately without testing
- D. Pin it harder.

Key: B.

## Q2

How do you check a model's lifecycle programmatically?
- A. The List Models endpoint's lifecycle field
- B. The model's name
- C. Claude's memory
- D. The price.

Key: A.

## Q3

Which is a capstone option?
- A. A single prompt
- B. A deck about Claude
- C. A list of links
- D. A plugin of three or more skills and connectors for a team

Key: D. Why: Options: agent team, plugin, or a tool built in Claude Code.

## Q4

What does the handover doc include?
- A. Purpose, models and effort, permissions, eval results, cost per run, known failure modes and an owner
- B. Only a logo
- C. Only the prompt
- D. Only the invoice

Key: A. Why: It also states how to update it.

## Q5

Which belongs in the monthly routine?
- A. Rewrite every prompt
- B. Read the release notes and check the lifecycle of every model in use
- C. Change models at random
- D. Delete the evals

Key: B. Why: Then rerun the evals if a model changed.

## Q6

A model your workflow calls has changed. What do you do?
- A. Nothing
- B. Raise effort
- C. Rerun the evals
- D. Block the connectors

Key: C. Why: Rerun the evals if a model changed.

## Q7

Menu names already differ between documentation pages. What follows?
- A. Ignore the docs
- B. Trust the oldest page
- C. Guess
- D. Check the live interface and the release notes before relying on a feature

Key: D. Why: Features change monthly.

## Q8

Which states can a model lifecycle report?
- A. Active, deprecated or retired
- B. Draft, review or final
- C. Free, paid or enterprise
- D. Small, medium or large

Key: A. Why: The List Models endpoint reports them.

## Q9

What happens in the live run?
- A. The learner shows a recording
- B. The examiner supplies a new input and the learner runs the capstone on it
- C. The examiner tests typing speed
- D. The eval is skipped

Key: B. Why: It proves the capstone works on unseen input.

## Q10

How does the learner close the course?
- A. Stop learning
- B. Memorise the release notes
- C. Self-assess against the 0 to 100 scale and list the next three skills to build
- D. Delete the capstone

Key: C. Why: Ship, hand over, watch.

## Fill in the blank

- Models have a lifecycle of active, deprecated or ____. Key: retired
- The handover doc states the cost per ____. Key: run

## Matching

Match each capstone item to what it is.

- Option A = An operations agent team for a real workflow, with approvals
- Option B = A plugin of three or more skills and connectors for a team
- Option C = A tool built in Claude Code with tests, hooks and a scheduled run
- Handover doc = Purpose, inputs, models, permissions, evals, cost, failure modes and an owner
