# Session 9 quiz: Skills

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Which frontmatter fields are required?
- A. name and description
- B. name, version and author
- C. description and license
- D. title and tags.

Key: A.

## Q2

A skill never triggers. First fix?
- A. Add more files
- B. Rewrite the description to say when to use it, in the words a request would use
- C. Switch to Haiku
- D. Raise effort.

Key: B.

## Q3

What part of every installed skill is always loaded?
- A. The full SKILL.md
- B. Its name and description
- C. Its scripts
- D. Nothing.

Key: B.

## Q4

Which name is valid for a skill?
- A. weekly-status-report
- B. Claude Weekly Report
- C. weekly_status_REPORT
- D. anthropic-status

Key: A. Why: Lowercase letters, numbers and hyphens, matching the folder name, without the words anthropic or claude.

## Q5

How long can a skill description be?
- A. 10 characters
- B. Up to 1,024 characters
- C. 100 characters
- D. There is no limit

Key: B. Why: Claude reads the description to decide when to load the skill.

## Q6

When does the SKILL.md body load?
- A. At the start of every chat
- B. Never
- C. When the skill is triggered
- D. Only on mobile

Key: C. Why: Progressive disclosure: name and description always, body when triggered.

## Q7

Which need should not be a skill?
- A. A weekly report format
- B. A repeated review procedure
- C. A task repeated the same way
- D. Live data from an app, which a connector supplies

Key: D. Why: Use a skill for a task repeated the same way, not for live data.

## Q8

How do you package a skill for upload?
- A. Zip the skill folder itself so the archive's top level is the folder
- B. Zip only the files, loose
- C. Email the folder
- D. Paste it into chat

Key: A. Why: Then upload under Customize, then Skills.

## Q9

Which is safe practice with third-party skills?
- A. Install any skill with many stars
- B. Read every file before use; use only skills you wrote or that come from Anthropic
- C. Run its scripts first, read later
- D. Trust the description

Key: B. Why: Scripts can touch files, commands and the network.

## Q10

What does skill-creator add in Cowork and Claude Code?
- A. Automatic publishing
- B. A new model
- C. A baseline run without the skill, with pass rates, timing and tokens
- D. A bigger context window

Key: C. Why: It measures the lift the skill gives.

## Fill in the blank

- The description must say what the skill does and ____ Claude should use it. Key: when
- The only required file in a skill folder is ____. Key: SKILL.md

## Matching

Match each part of a skill to its purpose.

- SKILL.md = Instructions, with name and description in the frontmatter
- References = Extra documents loaded only when a step needs them
- Assets = Templates and example outputs
- Scripts = Code run by path with the skill folder placeholder
