# Session 3 quiz: Choosing models and effort

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

A team classifies 50,000 support emails a day and needs low latency. Which tier is positioned for this?
- A. Fable 5.2
- B. Opus 5.5
- C. Sonnet 5.5
- D. Haiku 5.5.

Key: D.

## Q2

Unsure which model to use for a new workload. Anthropic's starting point?
- A. Haiku 5.5
- B. Sonnet 5.5
- C. Opus 5.5
- D. Fable 5.2.

Key: C. Why: Most workloads start with Opus 5.5; efficiency-first teams start with Haiku 5.5. Move to Fable 5.2 only if evals still fall short at higher effort.

## Q3

Fable 5.2 and Mythos 5.2 are:
- A. Two unrelated models
- B. The same underlying model with different access and safeguards
- C. A fast and a slow version of Haiku
- D. Retired models.

Key: B.

## Q4

A model spends long thinking on simple requests. What does the documentation suggest first?
- A. Switch to a larger model
- B. Lower the effort level
- C. Add more step-by-step instructions
- D. Raise max output tokens.

Key: B.

## Q5

What is Anthropic's efficiency-first way to start?
- A. Start with Fable 5.2 and move down
- B. Start with Haiku 5.5 and upgrade only where there is a specific capability gap
- C. Use Sonnet 5.5 for everything
- D. Pick the cheapest model and never test

Key: B. Why: Efficiency-first starts with Haiku 5.5.

## Q6

Which lever do the docs say is often better than switching models?
- A. Adding examples to every prompt
- B. Raising max output tokens
- C. Tuning the effort level
- D. Changing provider

Key: C. Why: Effort trades intelligence for latency and cost within one model.

## Q7

What does a model's lifecycle status tell you?
- A. Its price per token
- B. Its context window
- C. Its cutoff date
- D. Whether it is active, deprecated or retired, which decides if it keeps working

Key: D. Why: Anything pinned to a retired model ID stops working.

## Q8

In the executor and advisor pattern, what does the executor do?
- A. Does the work on a cheaper model and escalates hard decisions to the advisor
- B. Reviews every answer with a human
- C. Delegates bulk work to workers while a stronger model watches
- D. Sets the prices

Key: A. Why: The orchestrator and workers pattern is the other one.

## Q9

What is the first step of testing a model for your own use case?
- A. Read the model's marketing page
- B. Build benchmark tests from your real prompts and data
- C. Pick the highest price
- D. Run one prompt once

Key: B. Why: A good evaluation set is the most important step.

## Q10

Which statement about the four current models is correct?
- A. Only Fable 5.2 lists 1M context
- B. Haiku 5.5 has no vision
- C. All four list 1M context and 128K max output
- D. Max output differs tenfold between them

Key: C. Why: All four list 1M context, 128K max output, text and image input, vision and tool use.

## Fill in the blank

- Capability-first: start with ____ 5.5. Efficiency-first: start with ____ 5.5. Key: Opus; Haiku
- Effort trades intelligence for latency and ____ within one model. Key: cost

## Matching

Match each tier to its task.

- Haiku 5.5 = Classification, extraction and routing at volume
- Sonnet 5.5 = Speed and intelligence together
- Opus 5.5 = Default knowledge work and long-running agentic coding
- Fable 5.2 = The hardest reasoning and long-horizon agentic work
