# Session 11 quiz: Claude inside workflows

Contents: Q1 to Q10, fill in the blank, matching.

Ask one question at a time. Show the stem and options only. Hold the key until the learner has answered. Do not repeat a question in the same sitting.

## Q1

Where does the human approval step go?
- A. Before every read
- B. Before any step that sends or writes outside
- C. Once a year
- D. Nowhere.

Key: B.

## Q2

A workflow classifies thousands of tickets and drafts replies for the urgent ones. Best assignment?
- A. Fable 5.2 for everything
- B. Haiku 5.5 classifies, a stronger model drafts the urgent replies
- C. Haiku 5.5 drafts everything
- D. Any model, unmeasured.

Key: B.

## Q3

Which is the current model ID for Sonnet 5.5?
- A. sonnet-5.5-latest
- B. claude-5-sonnet
- C. sonnet55
- D. claude-sonnet-5-5

Key: D. Why: The IDs are claude-fable-5-2, claude-opus-5-5, claude-sonnet-5-5 and claude-haiku-5-5.

## Q4

Where is effort set in an API request?
- A. With adaptive thinking and an effort value in the output configuration
- B. In the model ID
- C. In the user message only
- D. In a response header

Key: A. Why: Effort is set with adaptive thinking.

## Q5

What is prompt chaining?
- A. Repeating one prompt many times
- B. Splitting a task into steps so each step gets one clear instruction
- C. Linking many models in one request
- D. One very long prompt

Key: B. Why: It is a named technique in the prompt engineering overview.

## Q6

A step returns invalid output. What happens?
- A. Pass it on anyway
- B. Retry forever
- C. Validate, retry once, then route to a human
- D. Delete the log

Key: C. Why: Ask for a fixed format and validate before the next step.

## Q7

Which tier suits classification, extraction and routing?
- A. Fable 5.2
- B. Opus 5.5
- C. Any tier, unmeasured
- D. Haiku 5.5, the cheapest tier

Key: D. Why: Use the cheapest tier for classification, extraction and routing.

## Q8

What belongs in the run log?
- A. Time, model, input, output and approver
- B. Only the output
- C. Only the price
- D. Nothing, to save space

Key: A. Why: Log each run.

## Q9

Which tools can host a Claude workflow?
- A. Only Claude Code
- B. Any tool with an HTTP step or a Claude node
- C. Only spreadsheets
- D. Only tools built by Anthropic

Key: B. Why: Node names vary, so read the tool's own documentation.

## Q10

Why split a workflow by difficulty?
- A. Every step needs the same model
- B. Models cannot do more than one task
- C. Cheap models handle the bulk and stronger models handle drafting and analysis
- D. It removes the need for approval

Key: C. Why: Split by difficulty.

## Fill in the blank

- Ask for a fixed format, validate, retry once, then ____. Key: route to a human
- Prompt chaining splits a task into steps so each step gets one clear ____. Key: instruction

## Matching

Match each workflow step to a model tier.

- Classify incoming items = Haiku 5.5
- Draft the reply = Sonnet 5.5
- Analyse and review against the source = Opus 5.5
- Orchestrate the hardest multi-step research = Fable 5.2
